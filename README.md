# Japanese Lingo Path

A product shell for a personalized Japanese learning platform.

## Included in this first version

- action-focused learner dashboard
- N5 learning-path structure
- empty lesson and content-block containers
- practice and spaced-review areas
- AI tutor and conversation shells
- JLPT and progress areas
- responsive desktop and mobile navigation

Learning content, question banks, account storage, AI services, and review algorithms are intentionally reserved for later phases.

## Local development

```bash
npm install
npm run dev
npm run build
```
